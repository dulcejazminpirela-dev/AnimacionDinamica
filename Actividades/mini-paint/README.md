# Mini Paint

Aplicación de dibujo hecha con HTML, CSS y JavaScript.

## Funciones
- Siete colores para dibujar.
- Tres grosores de pincel: delgado, mediano y grueso.
- Borrador.
- Botón para borrar todo el lienzo.
- Compatible con mouse y pantallas táctiles.

## Cómo usar
Abre `index.html` en un navegador web.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `mini-paint`.
2. Sube `index.html` y `README.md`.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio. El enlace aparecerá en esa misma sección.
